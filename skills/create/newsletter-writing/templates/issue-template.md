# Issue template

Replace every `<placeholder>`. Delete any section the issue's job doesn't need.

```text
JOB OF THIS ISSUE: <one line>
ISSUE: #<number> · SEND: <YYYY-MM-DD HH:MM tz> · SLUG: <issue-slug for UTMs>

SUBJECT: <specific, front-loaded, true>
SUBJECT B (test): <optional>
PREHEADER: <one line that adds to the subject>
```

---

**<Opener heading or none>**

<2–3 lines. Start with the most interesting true thing from this period: a number, a moment, a question a reader
asked. End with why the rest of the issue is worth reading.>

## <Main piece heading: the promise in plain words>

<The main piece. Short paragraphs. One idea per paragraph. The useful part first.>

<If it is a how-to:>
1. <step>
2. <step>
3. <step>

<One concrete example, with real numbers if you have them.>

<Image, if it helps: alt text "AI-generated image: <scene>" or a plain description for real photos.>
