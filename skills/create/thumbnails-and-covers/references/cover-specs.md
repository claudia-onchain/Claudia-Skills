# Cover, thumbnail and profile image specs (checked 2026-10)

[3P] = third-party guide; the platform publishes no single spec page or the page blocked fetching. Re-check before a launch.

## Video covers and thumbnails

| Item | Size | Notes |
|---|---|---|
| YouTube long-form thumbnail | 1280×720 (16:9), JPG/PNG | Standard spec (not re-fetched this session). Keep under 2 MB. Duration badge bottom-right. Test & Compare: up to 3 variants, judged by watch-time share (support.google.com/youtube/answer/13861714). |
| YouTube Shorts | frame chosen in the mobile app | Shorts are excluded from thumbnail Test & Compare per YouTube help; some 2026 guides claim 9:16 image tests on desktop — unverified. |
| Instagram Reels cover | upload 1080×1920 | Profile grid is **3:4 (1080×1440)** since Jan 2025: 240 px cropped top and bottom. Centred **1080×1350** survives 9:16, 4:5 and 3:4 [3P: hopperhq.com, oktopost.com]. |
| TikTok cover | frame + in-app text, or an uploaded image in-app | Keep the subject and title centred; same 1080×1350 rule is a safe default. |
| X video | first frame shows in the timeline on most clients | Open the edit on a strong frame. |

## Vertical UI zones on 1080×1920 [3P]

TikTok: top ~100, bottom ~250–350, right ~100–164 px. Reels: top ~250, bottom ~280 (ads guide: bottom 35 %), right
~100 px. Shorts: top ~100, bottom ~180, right ~80 px. Safe everywhere: the centred ~900×1400 area.
