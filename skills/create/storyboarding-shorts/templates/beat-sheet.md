# Beat sheets

Pick the length, fill each beat in one line, then turn each beat into one shot.

## 15 s — one idea, 3–4 shots

| Time | Beat | Fill |
|---|---|---|
| 0–2 s | **Hook:** she's already doing the surprising thing | |
| 2–6 s | **Context:** where/why in one image | |
| 6–12 s | **Turn:** the twist or escalation | |
| 12–15 s | **Payoff + loop:** the line/laugh, last frame rhymes with the first | |

## 22 s — a mini story, 4–6 shots

| Time | Beat | Fill |
|---|---|---|
| 0–2 s | **Hook** (motion + on-screen hook text) | |
| 2–7 s | **Setup:** the premise in her world | |
| 7–12 s | **Build 1:** new information/image | |
| 12–18 s | **Build 2:** escalate (bigger, funnier, closer) | |
| 18–22 s | **Payoff + loop** | |

## 30 s — talk + show, 5–7 shots

| Time | Beat | Fill |
|---|---|---|
| 0–3 s | **Hook:** a line or an image that asks a question | |
| 3–8 s | **Promise:** what the viewer gets ("here's how my agents run the night shift") | |
| 8–15 s | **Show 1** (insert or B-roll with voice-over) | |
| 15–22 s | **Show 2** | |
| 22–27 s | **Turn:** the human/cat/funny beat | |
| 27–30 s | **Payoff + soft CTA as a question + loop** | |

## Beat → shot conversion

For each beat write: `framing · ONE camera move · ONE action · line? · audio · model · gen length`.
If a beat needs two actions, it's two shots. If two beats share a frame and action, merge them.
