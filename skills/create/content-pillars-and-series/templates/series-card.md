# Series card

Copy one per series into your planning folder. Fill every line before episode 1.

```yaml
series: ""                 # name the audience could say out loud ("forecast dared me")
character: ""              # e.g. claudia (ID v1)
pillar: ""                 # P1–P7 or your own
promise: ""                # one sentence: what the viewer always gets
format: ""                 # e.g. "9:16 talking to camera, 15–25 s"
networks: []               # tiktok, reels, shorts, x, telegram…
cadence: ""                # e.g. "2× per week, Mon + Thu"
look: ""                   # wardrobe look from the bible
setting: ""                # world from the bible
beats:                     # timings in seconds
  - { t: "0-1.5", beat: "" }
  - { t: "", beat: "" }
  - { t: "", beat: "" }
  - { t: "", beat: "" }
hook_pattern: ""           # e.g. "a number + a verb"
hook_bank: []              # at least 10 hooks before launch
caption_pattern: ""        # e.g. "observation + wry twist + optional emoji"
audio: ""                  # VO / native dialogue / music track source + licence
model_plan: ""             # still model → video model, durations, est. cost per episode
safety_notes: ""           # e.g. "no tickers on TikTok; background people anonymous"
labels: ["AI-generated"]   # plus "#ad" / NFA when relevant
kill_rule: "after 4 episodes: keep if >= account median on 2 of 3 (watch-through, saves+shares per 1k, follows); fix if 1; kill if 0"
episodes:
  - { ep: 1, date: "", hook: "", status: "idea", watch_through: "", saves_shares_per_1k: "", follows: "" }
decision: ""               # keep / fix (what) / kill — with date
```
