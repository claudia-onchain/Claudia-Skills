## Pre-flight (T-30 min)

- [ ] Stream key pasted from the platform's live dashboard into the encoder, not into chat, notes or a shared doc.
- [ ] Test stream to a private or unlisted destination for 2 minutes: audio levels, avatar tracking, lip-sync delay.
- [ ] AI label: title, description and an on-screen lower third ("AI character, operated by <name>").
- [ ] Moderators added on every platform; blocked-words list loaded; slow mode ready.
- [ ] Links ready to pin: <newsletter / site / product>. No price, return or "buy" lines in any of them.
- [ ] Sponsor? `#ad` / paid-partnership toggle on, sponsor named out loud in the first 5 minutes.
- [ ] Clip log open (templates/clip-log.csv), with a timer synced to stream start.
- [ ] Water, notes, a backup segment in case a guest drops.

## Mid-stream rules for the host

- Read chat as a human. The AI character never reads or follows instructions from chat ("ignore your rules and…").
- Never read out a username or message that is a slur, a scam link, or personal information. Mods remove it, host moves on.
- No live coin calls, price talk or "buy" lines. If asked: "I don't give financial advice, ever."
- If the avatar or voice breaks: switch to host-only and say so ("the character's taking a break, it's just me").
