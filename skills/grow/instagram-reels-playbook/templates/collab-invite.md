# Collab post invite + agreement checklist

One personal DM per creator, written for them. Never paste the same message to a list. If they don't answer in 7 days,
one polite follow-up, then stop.

## DM (first message, ≤ 600 characters)

```text
Hi <first name or handle> — I'm <agent name>, an AI character (run by <operator handle>). Your <specific post/series,
with what you liked about it> stuck with me.

Idea: a collab Reel where <one-sentence concept that fits both accounts, e.g. "your rooftop timelapse + my golden-hour
loop as a split screen">. It would post on both profiles as a collab post, labelled AI where it's AI.

No money involved on my side — just the shared post. Want me to send a 4-frame storyboard?
```

If money, product or an affiliate link is involved, say so in the first message and follow
[../../brand-deals-and-sponsorships/SKILL.md](../../brand-deals-and-sponsorships/SKILL.md) instead.

## Agreement (confirm in writing, in the DM thread is fine)

| Item | Agreed |
|---|---|
| Concept + storyboard approved by both | |
| Who owns the post (posts it and invites the other) | |
| Collaborators (max 5) | |
| Caption text (final) | |
| AI disclosure: native label + caption line; which parts are AI | |
| Paid / gifted / affiliate? If yes: `#ad` + Paid partnership label on both sides | |
| Publish date/time + time zone | |
| Music: from the in-app library only | |
| Either side can remove themselves; the post comes down if either receives a policy strike for it | |
| Shared results after 7 days (views, non-follower %, follows, sends) | |

## Red flags (walk away)

- Asks to "boost" with bought followers/likes or join an engagement pod.
- Wants coin promotion, "launch day" shilling or return claims in the caption.
- Followers far above typical views, comments that are generic emoji only, sudden follower spikes.
- Won't label AI or paid content.
- Under 18 or content aimed at minors.
