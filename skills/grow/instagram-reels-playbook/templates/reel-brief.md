# Reel brief

Fill one per Reel. The agent fills everything except "Approved by"; a person fills that after seeing `preview()`.

## Basics

| Field | Value |
|---|---|
| Account | @handle (Instagram) |
| Series | e.g. Rooftop Hours / Night Shift / Small Confessions / Behind the Prompt |
| Goal | reach non-followers / saves / follows / collab reach |
| Publish slot | YYYY-MM-DD HH:MM (local time + time zone) |
| Trial? | no / yes — variant A, B or C, testing: hook / first shot / length / audio / cover |
| Collaborators | none / @handle (accepted? yes/no) |
| Paid or gifted? | no / yes → brand, what was given, contract ref |

## Export

- 1080×1920, 9:16, H.264/AAC, 30 fps, faststart, no other app's watermark.
- Text clear of top ~220 px, bottom ~320 px, ~60 px sides.
- Cover: 1080×1920 JPEG, face readable in the 3:4 centre crop.
- Alt text (for images/covers): describe what is shown and that it is an AI-generated character.

## Caption

```text
<hook line, ≤ 125 chars>

<context or question>

<search phrase> #tag1 #tag2 #tag3   (≤ 5 hashtags)
AI-generated character.
```

## Disclosures (tick all that apply)

- [ ] Native AI label on (app: Advanced settings → Add AI label; API: `labels.ai: true`)
- [ ] Caption line "AI-generated character."
- [ ] Paid/gifted/affiliate/own brand → "Paid partnership" tag + caption starts with `#ad`
- [ ] Mentions a coin/price → rewrite; if unavoidable: news only + "Not financial advice.", no UK/EU invitation to buy
- [ ] No claim that the character personally used a product
