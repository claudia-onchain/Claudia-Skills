# Pin copy template

Limits: title ≤ 100 characters (only the first ~40 may show, so the keyword goes first), description ≤ 800, alt text
≤ 500, link ≤ 2,048. Descriptions don't show in feeds but help Pinterest match searches. Every description says the
character is AI-generated.

## Formulas

```text
TITLE:       <search phrase>: <what makes this one specific>
DESCRIPTION: <what is in the image, one sentence>. <keyword phrase 2 in a natural sentence>. <keyword phrase 3 or a
             styling tip>. AI-generated character by <team>. <optional: where to see more>.
ALT:         AI-generated image: <who>, <wearing or doing what>, <setting>, <one detail>.
LINK:        <page that shows the same look or set; no shorteners>
```

Rules: no keyword lists, no hashtag piles, no "follow for more", no price or coin talk.

## Carousel (2–5 images)

```text
TITLE:  <search phrase>: <n> ways
IMAGE 1: the strongest look (the hook) · IMAGES 2–5: one change each (angle, light, accessory)
DESCRIPTION: what changes across the images + keywords + "AI-generated character by <team>."
ALT: one per image
```
