# Lead magnet brief

A lead magnet is the specific, useful thing someone gets for subscribing. Fill this in before you build it. If you
can't fill in "the one problem" in one sentence, the magnet is too broad.

| Field | Your answer |
|---|---|
| Newsletter name | <name> |
| Reader (one sentence) | <who, what they're trying to do, what's in the way> |
| The one problem this solves | <specific: "I don't know what to post this week", not "content strategy"> |
| Format | <checklist / template pack / swipe file / prompt pack / mini-course by email / tool / calendar> |
| Size | <consumable in 5–15 minutes; a magnet nobody finishes builds no trust> |
| Title (promise + specific) | <"30 hooks for AI character shorts, sorted by pillar"> |
| Where it's offered | <bio link / pinned post / end of each short / landing page / end of each issue> |
| Delivery | <welcome email 1 link / automatic download after double opt-in> |
| Consent wording on the form | <"Get the pack and a weekly email about <topic>. Unsubscribe anytime."> |
| Bridge to the newsletter | <how issue 1 continues what the magnet started> |
| AI disclosure | <"Made with AI, reviewed by <name>" on the cover or first page> |
| Success metric | <landing page conversion %, welcome-email click %, 30-day retention of magnet sign-ups> |
| Kill rule | <if conversion < <x>% after <n> visitors, swap the title or the format> |

## Landing page copy skeleton

```text
HEADLINE: <title of the magnet>
SUBHEAD: <who it's for> get <specific outcome> in <time>.
WHAT'S INSIDE:
- <item 1>
- <item 2>
- <item 3>
FORM: [email] [Get the pack]
UNDER THE BUTTON: You'll also get <newsletter name>, one email every <weekday>. Unsubscribe anytime.
<AI character> is an AI character; this pack was made with AI and reviewed by <name>.
```

## Do not

- Promise money, followers, returns or "guaranteed" results.
- Gate something that is already public elsewhere without saying so.
- Pre-tick a marketing checkbox, or hide the newsletter sign-up inside terms and conditions.
- Collect more than you need (email, and first name only if you'll use it).
