# Cross-promotion swap: pitch and agreement

Use for a newsletter swap (each writer recommends the other once), a recommendation exchange, or a paid placement.
Pick partners whose readers would actually want yours: similar topic, different angle, list size within about 0.5x–2x
of yours.

## Partner shortlist

| Newsletter | Writer | Topic overlap (1–5) | List size (stated) | Platform | Contact | Status |
|---|---|---|---|---|---|---|
| <name> | <name> | <n> | <n> | <beehiiv / Substack / Kit / other> | <email or DM, only if they list it for collabs> | <to pitch / pitched / agreed / ran / declined> |

## Pitch (email, or a DM only where they invite collab requests)

```text
Subject: swap idea: <their newsletter> x <your newsletter>

Hi <name>,

I write <your newsletter> (<n> readers, <one-line topic>). I've read <their newsletter> since <when>; <specific issue>
was the one I forwarded the most.

Idea: we each write a short recommendation of the other in one issue in <month>. I'd write yours myself and send it to
you for approval first. Our readers overlap on <topic> but we cover it from different sides: <yours> vs <theirs>.

Full honesty: <your newsletter> is written by <AI character>, an AI character, and edited by me, <operator name>. The
recommendation would say so.

If it's not a fit, no reply needed. Thanks for the newsletter either way.
<operator name>
```

## Agreement (confirm in writing, one message is enough)

```text
- Dates: <their issue date> and <your issue date>
- Placement: <top / middle / end>, <~50–80 words>, one link with a UTM tag (utm_source=<partner>&utm_medium=newsletter&utm_campaign=swap-<yyyymm>)
- Each side approves the copy about themselves before it runs
- Disclosure: "Recommendation swap: <partner> is recommending us in return." Paid placement: label it "Sponsored" / "Ad"
- No list sharing. Nobody receives anyone's email addresses. Readers subscribe themselves.
- After: share sends, clicks and new subscribers from the UTM within 7 days
```

## Recommendation copy skeleton (what you write about them)

```text
A newsletter I read: <name> by <writer>. <What it covers, in one specific line>. Start with <issue title> — <why>.
Subscribe: <link with UTM>
(Recommendation swap: <name> is recommending us this month too.)
```
